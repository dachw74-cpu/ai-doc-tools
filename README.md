# AI-инструменты для работы с документами и моделями

Набор инструментов, которые я разработал и использую в работе: MCP-сервер для ИИ-агентов, маршрутизация к языковым моделям с фолбэком, бенчмарк моделей.

Всё работает локально, без отправки данных во внешние сервисы.

## Состав

### `mcp-docs/` — MCP-сервер для работы с документами

Сервер по протоколу Model Context Protocol. Даёт ИИ-агенту (Chatbox, Cline, Claude Desktop) инструменты для чтения и анализа документов:

- **Чтение:** docx, xlsx, HTML/MHTML-выгрузки
- **Анализ:** целостность файла, сравнение версий, отслеженные правки и авторы, поиск по файлам
- **Смысловой поиск (RAG):** гибридный алгоритм — векторное сходство плюс лексический поиск с весами IDF, объединение результатов по RRF. Находит фрагменты, которые чистый векторный поиск пропускает (аббревиатуры, артикулы, кодовые обозначения).
- **Аудит:** инвентаризация каталога с SHA-256, контроль неизменности оригиналов

Сервер работает **только на чтение** — испортить документ через него нельзя.

### `model-router/` — маршрутизация к моделям

Маршрутизация запросов к языковым моделям с трёхуровневым фолбэком:

1. основная модель
2. резервная (другой провайдер)
3. последний шанс (минимальные требования)

На каждом уровне — оценка ответа. Если модель вернула пустой ответ или обрезала текст, запрос уходит на следующий уровень автоматически.

**Детекция деградации.** Отдельная эвристика ловит reasoning-модели, которые расходуют весь бюджет токенов на скрытые размышления и возвращают пустой ответ. При одной пробе это неотличимо от сбоя сети, при трёх — закономерность.

**Контроль стоимости.** Учёт суточной квоты провайдера, сверка локальной статистики с фактическим расходом.

### `model-router/check-models.mjs` — бенчмарк моделей

Автоматизированная проверка моделей: каждая проба выполняется трижды, решение принимается по большинству. В отчёт идёт распределение по попыткам, а не один вердикт.

Такой подход выявил класс дефекта, который при одиночной пробе выглядит как случайный сбой.

## Требования

- Node.js 20+
- Python 3.11+ (для части инструментов)
- Chrome или Chromium (для рендера, если используется)

## Запуск

MCP-сервер:

```bash
node mcp-docs/server.mjs
```

Самотест протокола:

```bash
node mcp-docs/smoke.mjs
```

Проверка моделей:

```bash
node model-router/check-models.mjs
```
